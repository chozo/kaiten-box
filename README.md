# 回転ボックス

ボックスを回転させて、ハムスターを外に出そう。

段ボール箱ごと重力を切り替え、ハムスターと積み木を同時に転がして出口を開ける、縦型のWebパズルです。時間制限も得点もない、じっくり解くパズルとして作っています（全5ステージ）。

## 遊び方

- **◀ ▶ で箱を左右に倒し、▲ でひっくり返します**（左右・上へのスワイプ、← → ↑ キー、A D W キーでも同じ）。箱は回したままになり、重力はいつも画面の下向きです。操作は**見えている向き**のまま受け付けます。
- 動けるものはすべて、壁や他のものに当たるまで同時に転がります。
- ▼ボタンはありません。重力はいつも画面の下向きなので、下に倒す操作は意味がないためです。開始時の無重力から最初の1手も、◀ ▶ ▲ のどれかになります。
- ボタンやキーを**押している間は、各オブジェクトの止まる場所が半透明で表示**されます。離すと確定します（押したまま指をボタンの外へずらすとキャンセル）。
- **積み木をすべての緑のスイッチの上で止める**と、出口の赤い扉が開きます。開いた出口からハムスターを外へ出せばクリアです。
- 「戻す」（Z キー）は何回でも1手ずつ戻せます。「やり直し」（R キー）でその面を最初からやり直せます。

## ルール

| 項目 | 内容 |
|---|---|
| 制限時間・得点 | ありません。何度でも戻したり、やり直したりできます |
| 進行 | 脱出すると次の面へ進み、5面を抜けると「ぜんぶ脱出！」画面になります。ステージ選択はありません |
| つづきから | 遊んでいるステージを localStorage（`hako-hamster-progress`）に保存します。途中で閉じると、タイトルに「つづきから（ステージn から）」と「はじめから」が出ます。5面を抜けると記録を消し、「はじめる」だけに戻ります |
| 手数 | 画面上部に手数と最短手数（BFSで計算）を表示します。最短手数で解けると★が付きます |
| 自己ベスト | ステージごとの最少手数を、このブラウザの localStorage（`hako-hamster-best-v2`）に保存し、「ぜんぶ脱出！」画面に表示します |
| 判定 | 潰れる判定はありません。ぶつかったら押し合わずに止まります |
| 扉 | その手で扉が開き、ハムスターが扉に押し付けられていれば、そのまま転がり出ます |

開始直後は無重力で、最初の切り替えから重力がかかります。

## 演出

1. **箱ごと回転**：倒すと箱が約0.24秒で90°（ひっくり返すと180°）回り、そのままの向きで止まります。ハムスターは画面に対していつも立っています。「戻す」では箱の向きも短く回して戻します。プレビューの文字や「でぐち」の札は、箱が回っていても読める向きで描きます。
2. **着地点プレビュー**：止まる場所をゴーストと点線で表示します。扉が開く手には「ひらく！」、脱出できる手には「脱出！」と表示します。
3. **着地の手応え**：squash & stretch、木くずのパーティクル、箱の小さな揺れが出ます。着地音は落下距離が長いほど低く重くなり、同じ手の中で次々に着地すると音程が少しずつ上がって連なります。4マス以上落ちたハムスターは目を回します。
4. **面のつなぎ**：脱出して約1秒後、箱が傾きながら左へ滑って退場します。次の面の箱は右から弾むように入ってきて、着地音が鳴ります（`CONFIG.clearHold` / `slideOut` / `slideIn`）。
5. **光と影**：光は画面の上から当たっている前提で描きます。上の壁が奥の面に落とす影、下側の照り返し、壁・積み木・ハムスターが右下へ落とす影、外枠のツヤを、すべて画面に固定しています。箱が回るたびに影の付き方が変わります。
6. **ハムスターの待機中の動き**：呼吸、まばたき（ときどき2回）、鼻と耳のぴくぴくがあります。プレビュー中は、転がる方向に目を向けて体を傾けます。
7. **全クリアのお祝い**：最後の面を脱出すると、白いフラッシュとファンファーレのあと、次の演出が続きます。
   - 画面の左右から紙吹雪が打ち上がり、その後も降り続けます。花火も次々に上がります。
   - 回る光の筋を背に、ハムスターが跳ねます。
   - 結果カードが下から弾んで現れ、「ぜんぶ脱出！」の文字が1文字ずつ跳ねます。各面の行が順に出て、最短の面は★が音付きで飛び出します。最後に「★ n/5」の集計を出します。
   - 演出は2枚のキャンバスに描きます。`#fx-back` はカードの後ろ（光の筋・ハムスター）、`#fx` はカードの手前（紙吹雪・花火・フラッシュ）です。

## 開発

依存のない素のHTML/CSS/JSです。画像ファイルは使わず、すべて Canvas で描画しています。音は Web Audio で合成しています。

```sh
npm install          # playwright-core（E2E・動画撮影用）・wrangler（公開用）・ffmpeg-static（動画書き出し用）
npm run dev          # http://localhost:5173/ で起動
npm run levels       # 全ステージの可解性・最短手数（最初の1手に「下」は使えない条件）・行き詰まり状態数を表示
npm run e2e          # インストール済みChromeで通しプレイ・画面サイズを確認（スクリーンショットは .e2e/）
npm run build        # 公開用のファイルを dist/kaiten-box/ に出力
npm run deploy       # build してから Cloudflare Workers（静的アセット）へ公開
```

| ファイル | 役割 |
|---|---|
| `logic.js` | 盤面の判定（重力移動・扉・BFSソルバー）。DOM非依存でNodeからも使う |
| `levels.js` | ステージ定義（`#` 壁 / `H` ハムスター / `B` 積み木 / `S` スイッチ / `exit` 出口の穴） |
| `game.js` | 描画・演出・入力・音。冒頭の `CONFIG` に調整値をまとめている |
| `tools/` | 簡易サーバー、ステージ検証、E2E、公開用ビルド（`build-dist.mjs`） |
| `tools/promo/` | 告知動画の台本・撮影用の見た目・撮影と書き出し（下の「告知動画」を参照） |
| `wrangler.jsonc` | Cloudflare Workers の設定（Worker名 `kaiten-box`、静的アセットのみ、game.chozo.net/kaiten-box のルート） |

最短手数は起動時に BFS で計算します。確認用の入口として `window.__game`（`snapshot` / `start()` / `title()` / `press(盤面の方向)` / `pressScreen(画面の方向)` / `screenDir(盤面の方向)` / `hold(画面の方向)` / `undo()` / `manual(true)` / `step(dt, n)` / `solution()` / `drawHamsterOn()` / `sfx`）を用意しています。

## 告知動画

`npm run promo` で、縦型の告知動画（1080×1920・30fps・30秒、H.264 + AAC、-14 LUFS）を作り直せます。出力先はアプリの隣の `../video/` で、動画はリポジトリに含めません。

| ファイル | 内容 |
|---|---|
| `../video/kaiten-box-promo.mp4` | 本編 |
| `../video/kaiten-box-promo-cover.jpg` | 表紙（エンドカードの最後のコマ） |
| `../video/work/` | 撮影したコマ（`frames/`）と音声（`audio.wav`） |

```sh
npm run promo                        # 全コマを撮影して書き出す（約1分）
PROMO_EVERY=15 npm run promo         # 15コマおきの静止画だけ撮り、一覧画像 ../video/work/sheet.jpg で構成を確認
PROMO_ENCODE_ONLY=1 npm run promo    # 撮り直さず、work/ の素材から書き出しだけやり直す（音量の調整など）
```

- 台本は `tools/promo/scenario.js` にあります。つかみ → タイトル → プレイ（プレビュー・脱出・足場・戻す・早送り）→ 全クリアのお祝い → エンドカード（公開URL）の順です。
- 撮影用の見た目は `tools/promo/promo.css` にあります。ショート動画アプリのUIがかぶる下20%・右15%を避けて、ゲーム画面を置いています。
- 撮影は `tools/promo/record.mjs` が行います。インストール済みの Chrome をヘッドレスで開き、`window.__game.manual(true)` と `step()` でゲームを1コマずつ進めながら撮影します。CSSアニメーションも動画の時刻に合わせて進めます。
- 効果音は、撮影中は鳴らさずに動画の時刻つきで記録します（`__game.sfx.record`）。書き出し時に OfflineAudioContext で同じ時刻に鳴らし直し、BGM（軽いビート）を重ねます。
- タイトルとエンドカードのハムスターは、ゲームと同じ Canvas の絵です（`__game.drawHamsterOn` で別のキャンバスに描く）。
- 台本の中だけ、全面を最短でクリアした記録を入れて、お祝いで ★5/5 を出しています。ゲーム本体は変えていません。

## ステージ（現在）

| 面 | 名前 | 最短手数 | 覚えること | 到達状態 / 行き詰まり |
|---|---|---|---|---|
| 1 | くぼみのスイッチ | 3 | くぼみに入った積み木は、箱を回しても抜けない | 34 / 0 |
| 2 | 積み木を足場に | 3 | スイッチ上の積み木にハムスターを乗せ、出口の高さに合わせる | 40 / 0 |
| 3 | 積み木で止める | 5 | 片方の積み木を止め役にして、もう片方をスイッチの上で止める | 102 / 0 |
| 4 | ふたつならべて | 7 | 隣り合う2つのスイッチに、積み木を2つ並べる | 63 / 0 |
| 5 | みっつの積み木 | 9 | 壁のくぼみ2か所に積み木をしまう（1面の応用） | 353 / 0 |

1・2面は手で描きました。3〜5面は「どの積み木を取り除いても解けない、または遠回りになる」（全部の積み木に役割がある）配置を自動で探し、その中から形のすっきりしたものを選びました。どの面も、どの状態からでも解けて（行き詰まり0）、最短の解き方は1通りです。

2026-10-05：「難しすぎる」という感想を受けて易しくしました。最短手数を 4/6/7 から 3/4/5 に減らし、詰む状態をなくしました。戻せる回数を無制限にし、扉が開いた手でそのまま脱出できるようにしました。続けて、制限時間と得点をなくし、自己ベストの記録を加えました。さらに4面・5面（最短7手・9手。5面は積み木3つ）を足し、ステージ選択はなくしました。2026-10-06：「つづきから」を加えました。タイトルを「重力は横向き、箱入りハムスター」から「回転ボックス」に変え、タイトル画面を一文の説明だけにしました。箱を正立に戻さず回したままにし、操作を画面の向き基準に変えました。▼ボタンをなくしました（最初の1手に「下」が使えないため、4面の最短は7手から8手になりました）。面のつなぎの演出、画面に固定した光と影、ハムスターの待機中の動きを加えました。ステージを手で整え、各面に「覚えること」を1つずつ置きました（自己ベストは保存キーを `-v2` にして記録し直し）。全クリアのお祝いを派手にしました。GitHub と Cloudflare に公開し、告知動画を作りました。公開URLを game.chozo.net/kaiten-box/ に移しました。
